GlyphCNN: classifying noisy letter glyphs

A compact convolutional network that reads badly-degraded 32×32 binary images of capital letters into one of 21 classes. This dashboard reports real, reproducible results generated by the project's own evaluation pipeline.

Overview

The task is 21-way classification of heavily corrupted letter images — random orientation, salt-and-pepper noise and out-of-range pixel values. The model is a three-block CNN (Conv → BatchNorm → ReLU → MaxPool, with dropout) and a fully-connected head.

Two results are reported side by side. The pretrained model — trained on the original full dataset — is evaluated on all 151 recovered glyphs. Separately, a from-scratch run retrains the network using only those 151 recovered images, showing the whole pipeline is reproducible end-to-end.

The 21 classes

Each tile is the pixel-wise average of every example in a class — noise cancels out and the underlying letter emerges. Counts show how few examples some classes have.

Examples per class

The dataset is small and imbalanced — from 4 to 15 images per class.

Training

From-scratch run on the recovered set with a stratified split, light augmentation, ReduceLROnPlateau scheduling and early stopping on validation loss.
